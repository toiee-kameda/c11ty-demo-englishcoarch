## 見出し（Heading）

見出しは `#` の数で階層を表します。

### H3 — セクションの小見出し

#### H4 — 補足説明などに使う

---

## テキスト装飾

- **太字（Bold）** は `**テキスト**` で書きます
- *斜体（Italic）* は `*テキスト*` で書きます
- ~~打ち消し線~~ は `~~テキスト~~` で書きます
- `インラインコード` はバッククォートで囲みます

---

## リスト

### 箇条書きリスト（Unordered）

- 多読（Extensive Reading）で語彙を増やす
- シャドーイングでリスニング力を鍛える
- スピーキング練習を毎日続ける
  - 鏡の前で話す
  - 録音して聞き返す

### 番号付きリスト（Ordered）

1. 学習目標を設定する
2. 週間スケジュールを組む
3. 毎日コンテンツに触れる
4. 定期的に成果を振り返る

## コードブロック（Code Block）

JavaScript のサンプル：

```javascript
// 英単語の復習リマインダー（サンプルコード）
const words = ['extensive', 'shadowing', 'acquisition'];

words.forEach((word, index) => {
  setTimeout(() => {
    console.log(`Review: ${word}`);
  }, index * 1000);
});
```

CSS のサンプル：

```css
.article-body {
  max-width: 65ch;
  line-height: 1.85;
  font-size: 1.0625rem;
}
```
